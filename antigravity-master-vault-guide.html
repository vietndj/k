Lỗi Thường Gặp Khi Đồng Bộ Kiểu Cũ

  • Phình to Git: Đẩy 2GB SQLite DBs và cache lên GitHub gây nghẽn repo, vượt quá giới hạn 100MB của GitHub.
  • Chặn vì lộ Secret: GitHub Push Protection chặn đứng các commit chứa API token (YouTube, Cloudflare, Telegram...).
  • Lỗi Sidebar UI: Copy đè database sang máy mới thường bị crash hoặc không hiển thị trên menu trái do lệch installation_id.

Nguyên Lý Master Vault Tối Ưu

  • GitHub = Nhạc Trưởng: Chỉ lưu script điều phối siêu nhẹ (~20KB), không lưu file nhị phân nặng.
  • Google Drive = Kho Vault: Lưu 1 file đóng gói duy nhất được nén gọn và đối soát mã băm SHA-256.
  • Zero Dependency: 100% Python Standard Library, không cần cài đặt pip hay package ngoài.
